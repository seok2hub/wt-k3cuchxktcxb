# WOD 타이머

크로스핏용 운동 타이머. 휴대폰 홈 화면에 추가하면 앱처럼 쓸 수 있고, 한 번 열어 두면 인터넷 없이도 열립니다.

## 사용법
- 앱을 열면 **Are You Ready?** 화면이 먼저 뜹니다. 화면을 누르면 타이머로 넘어가고, 이때 소리도 켜집니다.
  - 오른쪽 아래 **No** 를 누르면 작별 화면이 뜨고, 그 화면을 다시 누르면 처음으로 돌아갑니다.
  - 기기에서 '동작 줄이기'를 켜 두면 깜빡이지 않고 천천히 색이 바뀝니다.
- 모드: 타바타 / EMOM / AMRAP / For Time / 사용자 지정
- 키보드: **스페이스** 시작·일시정지 · **R** 리셋 · **F** 전체 화면 (시작 화면에서는 Enter·스페이스 = 시작, Esc = No)
- 큰 숫자를 눌러도 시작·일시정지됩니다.
- 마지막으로 쓴 설정과 저장한 설정은 기기마다 따로 기억됩니다.

### 동작 규칙
- 타바타와 사용자 지정에서는 마지막 라운드 뒤의 휴식을 생략합니다(타바타 기본값은 운동 3:50, 준비 포함 4:00).
- 사용자 지정에서는 사이클과 사이클 사이에 라운드 휴식 대신 "사이클 휴식"이 들어갑니다.
- EMOM의 총 시간이 간격으로 나누어떨어지지 않으면, 남는 시간은 빼고 진행합니다(설정 화면에 표시됨).
- For Time은 시간이 올라가며, 끝나면 위쪽의 **완료** 버튼을 누릅니다. 상한 시간에 도달하면 자동으로 끝납니다.
- 남은 라운드·사이클 수에는 지금 진행 중인 것도 포함됩니다.

## 휴대폰 홈 화면에 추가
- 아이폰(Safari): 사이트 주소를 열고 공유 버튼 → **홈 화면에 추가**
- 갤럭시(Chrome·삼성 인터넷): ⋮ 또는 ≡ 메뉴 → **홈 화면에 추가** (또는 **앱 설치**)

홈 화면 아이콘으로 열면 주소창 없이 화면 전체를 씁니다.

### 참고
- 아이폰은 무음 스위치가 켜져 있으면 소리가 나지 않습니다.
- 아이폰에는 웹페이지 전체 화면 기능이 없어 전체 화면 버튼이 보이지 않습니다. 홈 화면 앱으로 열면 됩니다.
- 화면 꺼짐 방지(Wake Lock)는 지원하는 브라우저에서만 작동합니다.
- 컴퓨터에서 `index.html` 파일을 더블클릭해서 열어도 타이머는 동작하지만, 오프라인 저장은 웹 주소(https)로 열 때만 됩니다.

## 파일을 고쳐서 다시 올릴 때 (중요)
1. `sw.js` 맨 위의 `const VERSION = 'v1';` 숫자를 하나 올립니다. (`v1` → `v2` → `v3` …)
2. 고친 파일과 `sw.js` 를 함께 올립니다.

앱은 열 때와 홈 화면에서 다시 앞으로 나올 때 새 버전이 있는지 확인합니다. 새 버전이 있으면 내려받아서, 설정 화면에서는 바로 새로고침하고 운동 중이면 끝나고 설정 화면으로 돌아올 때 바꿉니다.
설정 화면 맨 아래에 지금 버전(예: `버전 v2 · 오프라인 사용 가능`)이 표시되니, 바뀌었는지 여기서 확인하세요.
**VERSION 숫자를 올리지 않으면 이미 설치된 휴대폰에서는 예전 버전이 계속 보입니다.**

## GitHub Pages에 올리기

### 방법 A: 웹 브라우저에서만
1. https://github.com 에 로그인 → 오른쪽 위 **+** → **New repository**
2. 저장소 이름을 입력하고 **Public** 선택 → **Create repository**
3. **uploading an existing file** 을 눌러 아래 파일을 모두 끌어다 놓고 **Commit changes**
   `index.html`, `sw.js`, `manifest.webmanifest`, `apple-touch-icon.png`, `icon-192.png`, `icon-512.png`, `README.md`
4. 저장소 **Settings** → **Pages** → Source: **Deploy from a branch**, Branch: **main** / **/(root)** → **Save**
5. 1~2분 뒤 표시되는 주소(`https://<아이디>.github.io/<저장소 이름>/`)를 휴대폰에서 열고 홈 화면에 추가합니다.

### 방법 B: 명령어로 (git, GitHub CLI)
```bash
git add index.html sw.js manifest.webmanifest apple-touch-icon.png icon-192.png icon-512.png README.md
git commit -m "수정 내용"
git push
```
반영까지 1~2분 걸립니다.
